# Sourcing log

How every artifact class in the repository was produced, following [ADR 0004](adr/0004-sourcing-policy.md): native tool first, then official source, then open standards, and hand-writing only for what is ours. Research date: 2026-10-03. Claude Code facts come only from the official docs and changelog ([ADR 0003](adr/0003-clean-room-policy.md)); versions and licenses of generic tools were checked against their repositories on that date.
