# Changelog

Marketplace-level changes to Claude Essentials: plugins added, removed or deprecated, and changes to how the catalog is distributed. Each plugin keeps its own changelog in `plugins/<name>/CHANGELOG.md`.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the marketplace version follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-03

### Added

- Marketplace catalog `claude-essentials` with its category taxonomy and the non-affiliation disclaimer.
- `hello-example`, an example plugin that proves the pipeline end to end and will be removed once real plugins cover it.
- Repository gates, the plugin scaffold, the version bump script, the isolated install test, CI workflows, labels and contribution templates.
