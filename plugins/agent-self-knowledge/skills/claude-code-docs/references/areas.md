# Research areas

`ccdocs.py research` and `ccdocs.py inventory` read this table. It is the routing layer on top of the
official index (https://code.claude.com/docs/llms.txt): the index lists every page once, under one
navigation group; a topic lives on many pages, across groups and across sites.

## Columns

| Column | Meaning | Used for |
|---|---|---|
| **Area** | The topic's name. | Output labels. |
| **Triggers** | Words and short phrases that activate the area. A query phrase activates an area when a trigger occurs in the phrase or the phrase occurs in a trigger (plurals match). | Choosing areas; adding Claude Code pages whose index title contains a trigger. |
| **Terms** | The area's vocabulary: single words or short phrases as they appear in section headings. | Choosing which sections of each page to read. |
| **Nav groups** | Official navigation groups of `llms.txt` (`Section > Group > Subgroup`), separated by `;`. Every page of these groups belongs to the area. | Making the area complete. `selfcheck` fails when a navigation group is in no row. |
| **Pages** | Pages pinned to the area: backticked Claude Code slugs, or full Help Center (`support.claude.com`, Claude apps and Cowork) and Platform (`platform.claude.com`, API) URLs. | Pages the other columns can't find, and the other two sites. |

`ccdocs.py inventory` writes the resolved page list of every area to `references/area-pages.md`.
Edit this table, never that file. `ccdocs.py selfcheck --live` validates the slugs and the groups.
