# Support

## Before you ask

- Read the plugin's README: it lists requirements, usage examples and what the plugin runs.
- Update first: `claude plugin update <plugin>@claude-essentials`. Community marketplaces do not auto-update unless you turn it on.
- Check `/plugin` → **Errors** and `claude plugin list --json` for load errors.
- For problems with Claude Code itself, such as marketplaces that fail to add or plugins that fail to load, see the official [plugin troubleshooting guide](https://code.claude.com/docs/en/plugins/troubleshooting).

## Where to ask

| You want to                              | Go to                                                                                                                             |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Report a bug in a plugin or the catalog  | [Bug report](https://github.com/nerymurillohnd/claude-essentials/issues/new?template=bug_report.yml)                              |
| Propose a plugin or a significant change | [Plugin proposal](https://github.com/nerymurillohnd/claude-essentials/issues/new?template=plugin_proposal.yml)                    |
| Report a vulnerability                   | [Private vulnerability report](https://github.com/nerymurillohnd/claude-essentials/security/advisories/new), never a public issue |

Include your Claude Code version, the plugin version, your operating system and the exact steps. Do not paste secrets or private data.

This is a community project maintained in spare time; responses are best effort.
